# 香港电影档案馆

一个私人香港电影数字档案馆，用于保存香港电影的片名、影像与观看线索。

## 技术

- React + Vite
- JavaScript
- JSON 数据驱动
- 本地资源管理

## 当前版本

V1.9

## 运行

```bash
npm install
npm run dev
```

默认本地地址为 `http://localhost:5173`。
