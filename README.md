# 香港电影档案馆

一个私人香港电影数字档案馆，用于保存香港电影的片名、影像与观看线索。

## 技术

- React + Vite
- JavaScript
- JSON 数据驱动
- 本地资源管理

## 当前版本

V1.98

V1.x 基础建设阶段完成。下一阶段：V2.0 香港新浪潮专题展厅。

## 运行

```bash
npm install
npm run dev
```

默认本地地址为 `http://localhost:5173`。
