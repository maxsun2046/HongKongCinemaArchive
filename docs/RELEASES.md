# V1.x 发布记录

本文件记录香港电影档案馆 V1.x 阶段的稳定版本节点。版本标签用于在 Git 中准确恢复对应发布基线。

## V1.0：李小龙时代

首个正式开放展厅完成，收录《唐山大兄》《精武门》《猛龙过江》《龙争虎斗》四部核心影片。

Git 标签：`v1.0-bruce-lee`

## V1.2：嘉禾黄金十年

建立嘉禾黄金十年专题展厅，并形成相关影片、人物、公司与时间线的策展结构。

Git 标签：`v1.2-golden-harvest`

## V1.8：数字档案馆大厅

首页加入馆藏统计、时代脉络与近期入馆概览，形成数字档案馆大厅。

Git 标签：`v1.8-archive-hall`

## V1.9：个人收藏系统

完成云端资源、NAS、实体收藏、播放设备与观看记录的资源管理基础。

Git 标签：`v1.9-collection`

## V1.97：备份体系

建立 GitHub、本地电脑与群晖 NAS 的备份职责、恢复流程及多设备维护约定。

Git 标签：`v1.97-backup-ready`

## V1.98：V1 阶段冻结

V1.x 基础建设阶段冻结，作为后续 V2.0 香港新浪潮专题展厅的稳定起点。

Git 标签：`v1.98-v1-baseline`
